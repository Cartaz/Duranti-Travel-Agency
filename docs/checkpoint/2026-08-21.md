# Checkpoint — 21 agosto 2026

Questo checkpoint verifica lo stato della PWA Diario di viaggio dopo l'introduzione di diario giornaliero, media locali, template di giornata e gestione dei template personali.

## Automazione

Il branch `chatgpt/checkpoint-tests` estende temporaneamente il workflow esistente con due verifiche, senza distribuire il branch su GitHub Pages:

1. `node tests/checkpoint/static-checks.mjs`
2. `timeout 6m node tests/checkpoint/browser-checkpoint-v2.mjs`

La regressione browser usa Chrome headless reale, IndexedDB e OPFS del browser. Non usa mock di storage.

## Risultati verificati

Il run GitHub Actions 212 ha completato con successo:

- `npm ci`

## Difetti trovati durante il checkpoint

Il controllo statico ha evidenziato due conferme native residue:

- archiviazione viaggio
- rimozione di un viaggiatore dal viaggio

Entrambe sono state sostituite con `InlineConfirm`. Il checkpoint statico ora fallisce se `window.confirm`, `window.alert` o `window.prompt` ricompaiono nelle feature quotidiane e nella UI condivisa (escluso il laboratorio storage diagnostico).
